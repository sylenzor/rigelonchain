Give your AI eyes on Solana.

Rigel Protocol is an open-source MCP server that connects Claude, Cursor, and any MCP client to the Solana blockchain and pump.fun — wallet balances, token data, and rug-risk checks, straight from a prompt.

$npm i -g @rigel-protocol/solana-mcp ★ Star on GitHub

Read-only. No private keys, no signing, no custody — Rigel only reads public chain data.

claude desktop — rigel-solana-mcp

Tools

Three tools. Zero setup on-chain.

Registered automatically the moment your MCP client connects. Ask in plain language — your AI picks the tool.

rigel_get_wallet_balance

Wallet X-ray

SOL balance plus a summary of major SPL token holdings for any public wallet address.

in walletAddress · out SOL, token list, USD est.
rigel_inspect_token_data

Token inspector

Live metadata, supply stats, bonding-curve SOL, and completion percentage for pump.fun tokens.

in tokenAddress · out metadata, curve %, supply
rigel_analyze_rug_risk

Rug radar

Mint & freeze authority status and top-holder concentration, folded into a formatted risk report.

in tokenAddress · out risk report (low/med/high)
Install

Connected in under a minute.

Works with Claude Desktop, Cursor, and any client that speaks MCP over stdio.

Install the server

Grab it from npm: npm i -g @rigel-protocol/solana-mcp

Add the config

Paste the block below into claude_desktop_config.json and restart Claude.

Ask your AI

"What's in this wallet?" · "Inspect this token" · "Is this a rug?" — Rigel handles the chain.

claude_desktop_config.json 
{
  "mcpServers": {
    "rigel-solana": {
      "command": "npx",
      "args": ["-y", "@rigel-protocol/solana-mcp"],
      "env": { "SOLANA_RPC_URL": "https://api.mainnet-beta.solana.com" }
    }
  }
}
Security

Built to be trusted with nothing.

The safest wallet integration is the one that never touches a wallet.

✓Read-only by design

No private keys, no transaction signing, no custody. Rigel can look, never touch.

✓Runs on your machine

Local stdio transport — your prompts and queries never pass through a third-party server.

✓Open source

MIT-licensed TypeScript. Read every line before you run it. PRs welcome.

✓Your RPC, your rules

Point it at any Solana RPC via SOLANA_RPC_URL — public, Helius, Triton, or your own node.
